# 0.0.4-beta.2

This prerelease corrects the Obsidian review findings from beta 1 and includes the README installation update. **Obsidian 1.13.0 or later is required.** Settings use the declarative API exclusively; there is no legacy settings renderer.

## Review corrections

- Move the view container and fixed-position measurement probe's static styles into `styles.css`.
- Apply editor mode-menu and touch-action overrides through `setCssStyles`, preserving their existing values and layout.
- Use cross-window-safe `instanceOf(HTMLElement)` checks for typed DOM elements.
- Type the find-highlight plugin's internal transaction metadata before returning its state.
- Use browser-window timers in the save cooldown and immediate shims, and replace the shim's `globalThis` target with `window`.
- Run the asynchronous debounced rename from a void timer callback and retain its error handling.
- Register all four plugin settings through `getSettingDefinitions`, with validated persistence and editor refresh through `setControlValue`.

## Preventing recurrence

Local lint and CI now enable all reported rules, including the type-aware unsafe-return and misused-promise checks. Lint includes the CommonJS shim and runs with `--max-warnings=0`.

Running the strengthened configuration against beta 1 reproduced 34 style violations plus all reported warning categories: unsafe return, window timers, cross-window type checks, asynchronous timer callback, settings definitions, and `globalThis`. The corrected source has zero lint errors and warnings.

## Validation

- Seven unit tests, including declarative settings discovery, defaults, validation, persistence, and refresh behavior.
- Three live Obsidian settings checks: all four settings registered for search, native text input validation/persistence, and native language/toggle controls. Original settings are restored afterward.
- Sixteen general vault checks, including editor host dimensions, mode-menu layout, actual keyboard input, save/reopen, find/replace, autosave, rename, review markup, pagination, read-only embeds, and unchanged existing open DOCX files.
- Eleven ruler checks, including fast movement in both directions at 75%, 100%, and 150% zoom, stable viewport, consistent section properties, and saved/reopened/autosaved margins.
- A clean lockfile installation, production build, and strict lint in a separate temporary directory.

Repeat the live checks with the intended running Obsidian vault and its CLI enabled:

```sh
OBSIDIAN_TEST_VAULT="Test vault" npm run test:settings
OBSIDIAN_TEST_VAULT="Test vault" npm run test:vault
OBSIDIAN_TEST_VAULT="Test vault" npm run test:rulers
```

The [beta 1 report](0.0.4-beta.1.md) documents the existing editor dependency workarounds and ruler investigation. Physical mobile devices were not tested.
